# Loan-Advisor

Future. Customer-facing Angular app for banking loan customers —
the portal that will eventually ask questions of the RAG system
built on the Datagen corpus.

Not built yet. When it is built it gets its own folder here, with
its own build, its own Dockerfile (if any), and its own
deployments. It talks to the RAG system through the
`Middleware/API-Services/` APIs, never directly to Datagen.
