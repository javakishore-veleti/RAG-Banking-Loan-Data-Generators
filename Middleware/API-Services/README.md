# API-Services

Future. Server-side APIs that will sit next to the Datagen
workflow — for example a loan-query / RAG-answer API that serves
the Loan-Advisor portal.

Not built yet. When the first one is built it gets its own folder
here, with its own Dockerfile and its own deployments, exactly
like `Workflows/Datagen/`. It must not reuse Datagen's image.
